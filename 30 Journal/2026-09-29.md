## Leçons de méthode (portées dans la skill `unity-android-game`)

- Deux Unity sur le **même projet** = `Fatal Error! … another Unity instance`
  → sérialiser les passes, vérifier zéro instance avant de lancer.
- Un `private static readonly` de catalogue est **invisible aux tests** (CS0117).
- Vérifier le C# **généré** avant de lancer Unity : une accolade manquante dans
  un `new List<T>` donne `CS1526` sans pointer le générateur (ici 12 blocs).
- Ne jamais réécrire un fichier lu partiellement : un script de sprites de 148
  lignes a été réduit à 1 ligne — utiliser `patch`, et garder sous git.
- Table tirée d'un JSON : vérifier les `roll` réels (d6=5 = sylvanian,
  ecumenopolis = d6=6), ne pas supposer l'ordre des entrées.
- `numpy` cassé dans le sandbox Hermes → mesurer en **PIL pur**.
- Le fond d'une scène **se peint** (`kit.Image(background, UiPalette.Background)`) :
  un `Create("Background")` seul donne une capture **noire**.
- Une grille de N boutons sur **une** rangée tronque les libellés →
  `GridLayoutGroup` `FixedColumnCount = 3`.
- La **hauteur de glyphe n'est pas la `fontSize`** : 20 px déclarés = 14 px
  mesurés (< 16). Mesurer l'encre sur un libellé non sélectionné.
- Le fond d'un panneau (43,39,48) doit servir de seuil pour mesurer le texte,
  pas le fond global — sinon les bandes font 325 px.
- Un contrôleur qui met la session en cache dans `Start()` est **vide** pour la
  capture (la partie est créée après) : lire la session à la demande.
- Deux blocs ancrés en bas se **chevauchent** si leurs offsets se recouvrent :
  sommer les hauteurs des boutons + espacements avant de fixer la boîte.
- Sur une police **monospace**, le nombre de caractères se mesure
  (`largeur_px / largeur_caractère`) : c'est ce qui tranche quand la vision se
  contredit sur les espaces et les débordements.
- Le **carrousel horizontal** montre la carte suivante au bord droit : la vision
  y voit un « bloc qui dépasse ». Mesurer la marge du bloc *central* avant de
  conclure — c'est une affordance de défilement.
- Un `OriginDefinition` porte `portraitAssetId` **et** `portrait` : le lieur
  écrit dans `portrait`, le prefab est rechargé après (re-câbler en dernier).
- Images IA : OpenRouter (`google/gemini-3.1-flash-image`, clé du compte de raf)
  rend une image 848×1264 en ~40 s ; la charte doit être répétée dans le prompt
  (fond indigo, éclairage rose, pas de texte). En 1408×768 (vaisseaux) c'est ~55 s.
- **Illustrations d'ennemis (18 vaisseaux du livre)** : table `EnemyShipArt` portée
  par la **vue**, remplie par `SetArray` depuis le générateur (`ship_<id>.png`) —
  pas de dossier `Resources`, convention du projet. Vérifier le `using` du
  namespace (`Rules.Space`) : l'oubli donne CS0103 au lieu d'un échec de câblage.
- **Ne jamais lancer deux Unity sur le même projet** : le second reste bloqué sur
  `Temp/UnityLockfile` sans écrire de PNG (31 min perdues). `pkill -9` puis
  supprimer le verrou avant de relancer.
- Estomper un art à coque 0 rend la preuve ambiguë en vision (elle conclut « pas
  d'illustration »). Garder l'art net, la bannière de mort suffit.
