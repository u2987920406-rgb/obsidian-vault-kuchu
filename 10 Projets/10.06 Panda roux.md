# 10.06 Panda roux — Animation de personnage

Projet d'apprentissage de **modélisation et d'animation de personnage** dans
Blender, sur le BMAX. Objectif : modéliser puis animer un **panda roux
cartoon simple**. Premier personnage 3D de kuchu.

## Où ça vit

- Code et livrables : `~/projets/panda-roux/`
- Modèle : `panda_roux_v7.blend`
- Rendu : `renders/v7/` (5 vues) · planche `renders/planche_v7.png`
- Notes de production complètes : `~/projets/panda-roux/NOTES.md`
- Outil : Blender 5.2.x LTS (via Steam, mises à jour automatiques)

## Méthode retenue

Modélisation **par script Python (bpy)** plutôt qu'à la main, choix explicite
de Raf. Avantages : reproductible, versionnable, itérable vite.
Limite connue : le modelage organique fin (sculpture) reste meilleur à la
main — la voie script convient pour une base cartoon.

Détail des pièges techniques : `NOTES.md` du projet (4 pièges documentés).

## Pièges techniques (réutilisables)

1. **Metaballs + rayon variable = chapelets de boules.** Pour un membre, un
   tube balayé le long d'une spline (Catmull-Rom + repères de Frenet).
2. **Ce qui doit être soudé doit exister avant le `voxel_remesh`.**
   Ordre imposé : construire → fusionner → détailler.
3. **Le lissage `SMOOTH` rétracte les formes fines** (les pattes se
   détachent). Peu d'itérations + subdivision.
4. **Colorer par faces = bords pixelisés.** Coloration par sommets
   (`FLOAT_COLOR`, domaine `POINT`).

## Suite

1. **Rig** — squelette + poids (prochaine étape).
2. **Animation** — une marche, puis une scène courte.
3. Le modèle est livré **d'une seule pièce** (collection `Panda_Roux_v7`),
   prêt pour le rig.
